# SPEC-BUG-159 — Vulnerability and supply-chain gates

## Outcome

Implemented repository-local workflow hardening and deterministic configuration
validation. CI now runs the reachable Go vulnerability and high-severity Go
security analyzers, and PR dependency review rejects newly introduced moderate
or higher severity vulnerabilities.

## Acceptance Criteria

| Criterion | Status | Evidence |
| --- | --- | --- |
| AC1 | Configured | Weekly CI and PR-triggered `make security` run `govulncheck ./...`. |
| AC2 | Configured | `make security` runs `gosec -exclude-generated -severity high ./...`; the local policy rejects all current `#nosec` suppressions and documents the required future-review fields. |
| AC3 | Passed | Hermetic command-path fixtures prove the configured `govulncheck` and `gosec` invocations reject controlled known-bad results without changing production configuration or querying advisory services. |
| AC4 | Configured | PR-only pinned Dependency Review action uses `fail-on-severity: moderate`. |
| AC5 | Passed | Every workflow `uses:` reference is a full immutable SHA with version comment; Renovate enables `helpers:pinGitHubActionDigests`. |
| AC6 | Passed | Workflow defaults are read-only; only `release` has a job-level `contents: write` grant. Desktop builds retain read-only tokens. |
| AC7 | Passed | Wails CLI install is pinned to `v3.0.0-alpha2.117`, matching `go.mod`; local policy check rejects `@latest`. |
| AC8 | Passed by configuration review | Scanner output is neither uploaded nor written through a secret-expanding shell expression. |
| AC9 | Passed locally except live scanner queries | See validation evidence below. |

## Validation evidence

- `make security-config-check` — PASS.
- `make security-self-test` — PASS; both controlled scanner-result probes
  returned nonzero and the Make targets propagated the failures.
- Controlled mutable-action probe — PASS (the local policy checker rejected an
  `actions/checkout@v4` substitution).
- `make script-check` — PASS (including actionlint).
- `go mod verify` — PASS.
- `go mod tidy -diff` — PASS.
- `make quality` — PASS.
- `go test -race -count=1 -timeout 5m ./...` — PASS.
- `make security` — deliberately not run locally: `govulncheck` obtains current advisory data and the run constraint allowed no security-service contact. CI owns that live gate; its command paths are covered by `make security-self-test`.

The Go linker emitted pre-existing macOS deployment-target warnings during build
and tests; all commands exited successfully.
